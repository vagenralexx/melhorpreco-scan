# Digitalizar com Melhor Preco

Digitaliza do scanner (WIA, TWAIN e rede) e salva PDF, JPG, PNG ou TIFF.

Baixe o instalador em [Releases](https://github.com/vagenralexx/melhorpreco-scan/releases/latest).

Usa o NAPS2.Sdk (LGPL 2.1 ou posterior); os textos das licencas vao na pasta LICENSES do programa.
